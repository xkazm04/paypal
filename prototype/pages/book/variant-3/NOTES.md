# Query Desk

## The bet
The query itself is the instrument. The verbatim JSON sits in an editable field beside a clause board that lights every position the closed BookQuery language allows, so nothing can hide in a query. Keyboard-first, with the outlook in a status bar.

## How a person uses it
1. Press 1–7 for a preset or / to ask in words. Layer 1 shows the text, the board and one verdict chip (valid, or invalid with an error count).
2. Click a position or type to change the query; edits validate live and an invalid query cannot run. A red "!" on a board row opens its errors.
3. Ctrl+Enter runs read-only; the board folds to the verbatim query on one line, then group lines and rows.
4. j/k selects a row and fills the inspector (Layer 2): PayPal ids, who decided, audit, market band, quarantined note. Enter opens the deal; x, a and ? export, audit and list keys.
5. Each status-bar item says "if you do nothing"; a click opens its detail.

## What it does better than the other two
Most honest about what the language can ask, fastest for a returning owner, and the only place Maya can correct a query herself.
