# The Sentence

## The bet
An owner reads a sentence faster than a form: "Your 6 agents may act inside your mandates. They run on claude-code, bound by M-12 v3 and 2 more…". Each fact is an underlined phrase: wavy red when it blocks money, a gold mark when only Maya can set it. Below: a command line and a "Who can set what" ledger, where the agents column always says "never".

## How a person uses it
1. Layer 1: the sentence, one hint line, the command line and a compact ledger (setting · now · agents), grouped by who can set it.
2. Click or Tab to a phrase, or click a ledger row. Layer 2 is a popover: state, who, one act, "silent → …".
3. "More…" opens the sheet with the full story (probe, keychain, mandates, HOUSE, idle lock); "Who moves money" opens the three authorities.
4. Or press `/` and type a command (`probe`, `sign mandate`, `pause`). Privileged commands open the approval window; the line wipes anything that looks like a pasted secret.

## What it does better than the other two
Densest and most keyboard-first: the whole configuration, including the fixed items (idle-lock length, SANDBOX mode, pinned HOUSE key), sits on one screen.

## Known limits
- With many gaps the sentence wraps to three lines.
- A popover covers part of the ledger while open.
- Commands need discovering; suggestions help.
