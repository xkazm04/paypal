## Goal (not a script)
The owner drafts or says a rule, sees what it would have done against last week (what-if), and signs it in the approval window.

## Definition of done (user POV)
The rule is signed once, its effect on last week is shown in dollars before signing, wallet-wide limits visibly sit above agent rules.

## Reachable surfaces
Preview server (`env.md`) windows/modules named by the Characters' Surface binding. Native shell is out of L2 scope.
